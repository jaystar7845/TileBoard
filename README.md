# TileBoard 2.10.2 (ready-to-use build)

An unchanged copy of the TileBoard 2.10.2 build, a dashboard for Home Assistant.

TileBoard was created by Alexey Ivanov (@resoai) and its contributors, and is MIT-licensed
(see `LICENSE.md`). The original repository, github.com/resoai/TileBoard, is no longer online,
so this copy is kept here so the Starline Smart Living setup guides always have a working download.

## Download

Open **Releases** (right-hand side of this page) and download `TileBoard_build_2.10.2.zip`.

## Install

1. Unzip it.
2. Upload the folder into Home Assistant's `www` folder and name it `tileboard`.
3. Add your `config.js` to that folder (start from `config.example.js`), then open
   `http://<your-home-assistant>:8123/local/tileboard/index.html`.
